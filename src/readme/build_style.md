# Style

The `style.css` file defines the visual appearance and responsive behavior of a generated Mark Two page.

It does not generate the page structure.

The HTML structure is generated by the renderer, while this stylesheet controls:

- colors
- typography
- spacing
- layout
- navigation
- banners
- article content
- images
- mathematics
- lists
- sidebars
- environments
- dark mode
- responsive behavior

---

# Global Styling

## Universal Box Sizing

1. Select every element:

       *

2. Set:

       box-sizing: border-box

3. This causes padding and borders to be included in an element's declared width and height.

7. Proposition uses its own accent, border, and fill.

8. Remark uses its own accent, border, and fill.

9. Example uses its own accent, border, and fill.

10. Conjecture uses its own accent, border, and fill.

11. Notation uses its own accent, border, and fill.

12. Warning uses its own accent, border, and fill.

13. Each environment therefore inherits the same structure while receiving its own visual palette.

# Responsive Layout

1. Apply the following media query:

       @media (max-width: 980px)

2. Reduce the header minimum height from:

       360px

   to:

       300px

3. Make the navigation use the full available width:

       width: 100%

4. Reduce the navigation corner radius:

       border-radius: 22px

5. Reduce the banner minimum height from:

       300px

   to:

       240px

6. Change the page layout from two columns to one:

       grid-template-columns: 1fr

7. Reduce the article/sidebar gap to:

       24px

8. Remove sticky positioning from the sidebar:

       position: static

9. The article and sidebar therefore become vertically stacked on smaller screens.

# Overall Styling Flow

1. Load the global variables.

2. Determine whether the document is in light mode or dark mode.

3. Apply the corresponding color variables.

4. Apply global box sizing and typography.

5. Create the outer page shell.

6. Build the header vertically.

7. Place the navigation above the banner.

8. Use the banner image as a viewport-wide background layer.

9. Place the banner title above the image.

10. Create the main page grid.

11. Place the article and sidebar into the grid.

12. Style:

    - article titles
    - sections
    - subsections
    - paragraphs
    - inline formatting
    - images
    - captions
    - mathematics
    - lists

13. Style the sidebar.

14. Style:

    - table of contents
    - related links
    - cross references
    - active TOC entries

15. Style semantic mathematical environments.

16. Override the corresponding colors and surfaces in dark mode.

17. At widths below `980px`:

    a. Change the two-column layout into one column.

    b. Make the sidebar non-sticky.

    c. Reduce header and banner dimensions.

18. At widths below `640px`:

    a. Reduce page padding.

    b. Reduce navigation dimensions.

    c. Reduce banner dimensions.

    d. Reduce article padding and corner radius.

19. The final result is a responsive Mark Two page whose structure comes from the renderer and whose appearance and behavior are controlled by CSS and JavaScript.
